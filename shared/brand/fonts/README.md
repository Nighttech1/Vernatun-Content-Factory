# Шрифты Вернатуна

Основной шрифт для новых материалов клуба и Mini App — **Glanz Regular** Василия Шишкина. Набирайте текст файлом `Glanz.otf` (400). Для курсива подключайте `Glanz-Italic.otf`. Армянские буквы набирайте Noto Sans Armenian. Кириллица, латиница, цифры и ₽ входят в Glanz. Лицензия из архива автора сохранена в `Glanz-License.txt`. Параметры и SHA-256 указаны в `vernatun-fonts.json`. Старые файлы сохраняются для воспроизведения прежних выпусков.
