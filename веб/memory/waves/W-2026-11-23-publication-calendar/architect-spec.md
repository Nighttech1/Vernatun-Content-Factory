# Календарь публикаций
Исходная рабочая ревизия c6dd74e42b35dffa01fd3f0f42378caae0eed759. В main до начала волны нет приложения /growth. Обновление использует рабочую ветку выпуска и текущий проверяемый контракт editorial-source.
Критерии: при открытии /growth видны выпуски текущей московской недели; весь календарь доступен без сортировки по этапам. Для каждого видны дата, формат, тема, канал, ответственный и задание. Анонсы используют ту же редакцию. Артикулы, старые замеры и ручные правки сохраняются. Публикация подтверждается фактом отдельно.
