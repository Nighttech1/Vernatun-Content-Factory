# Выполнение
Клиент/архитектура: проверены действующий API, канон двух месяцев, источник рабочей ветки и отдельная таблица редакции. Календарь — представление уже синхронизируемой редакции. Разработка: временной фильтр, анонсы для встреч и обновление контентных заданий. Существующий порядок выпуска — проверка схемы, проверка сборки и браузером, затем выпуск того же артефакта. Сайт и карточки сами не публикуют сообщения.
